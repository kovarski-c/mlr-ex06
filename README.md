# E-bikes Project — MLR Exercise 6

Will the e-bike finish the trip? Prediction of `runs_out` on 1800 synthetic
trips (synthetic teaching data — **not** a real battery model or fire-risk
predictor). The notebook (`ex06_notebook.ipynb`, Tasks 4a–4c) builds the
cleaning + feature + baseline pipeline; `bayes_compare.py` extends it with an
Optuna comparison of five model families.

## Files

| File | Role |
| --- | --- |
| `ex06_notebook.ipynb` | the course notebook (data loading, cleaning, features, baseline, teacher demo) |
| `ex06_ebikes.csv` | experiment data (1800 rows); also used by the notebook loader |
| `common.py` | notebook pipeline copied out with behavior preserved: loading, fixed physical cleaning, `add_energy` / `add_extended_features`, baseline forest, fixed split and CV |
| `bayes_compare.py` | Optuna comparison: k-NN, SVM, logistic regression, random forest (100 trees), HistGradientBoosting |
| `trials.csv` | every trial: family, trial number, applied parameters, CV mean, fold SD |
| `results.csv` | best config per family + reference rows (notebook baseline forest, majority class) |
| `convergence.png` | best-so-far CV accuracy vs completed trials, per family |
| `report.html` | self-contained report (embedded plot, tables, versions, limitations) |

## Run from a fresh clone

Requires [uv](https://docs.astral.sh/uv/) (`brew install uv` or
`curl -LsSf https://astral.sh/uv/install.sh | sh`).

```bash
git clone <your-mlr-ex06-url> && cd mlr-ex06
uv sync                                    # creates .venv from uv.lock
uv run python bayes_compare.py --trials 2 --cv-only   # smoke test (skips all test prediction)
uv run python bayes_compare.py --trials 20            # full comparison + report.html
```

`--cv-only` skips every test prediction and scoring step; the test subset is
only touched at the very end of a full run, after all choices are fixed.

## Measured runtime (Apple Silicon Mac, macOS 26, Python 3.13.12 via uv)

| Command | Wall time |
| --- | --- |
| `uv sync` (warm uv cache) | ~1 s |
| `--trials 2 --cv-only` smoke test | ~8 s |
| `--trials 20` full run | ~2–3 min (HistGradientBoosting dominates, ~110–140 s of it) |

Reproducibility: three consecutive `--trials 20` runs produced byte-identical
`results.csv` and `trials.csv` (fixed seeds, sequential Optuna with
`n_jobs=1`).

## Fixed protocol (no post-hoc choices)

* Split: `test_size=0.25`, `stratify=y`, `random_state=42`; test held out for
  a single final evaluation after all selections.
* Selection: training subset only, `StratifiedKFold(n_splits=3, shuffle=True,
  random_state=0)`; imputation, engineered features and `StandardScaler`
  (k-NN/SVM/logistic only) are pipeline steps refitted inside every fold.
* Preparation search is limited to mean/median numeric imputation and
  original/engineered features; cleaning and categorical encoding are fixed.
* Seeds: TPE `seed=0` and `n_startup_trials=5` per family, forest and
  HistGradientBoosting `random_state=0`.
* Overall winner selected by CV mean, never by test score. Fold SD (ddof=0)
  is context, not a significance test — see the limitations section in
  `report.html`.

The hand-in review `REVIEW.md` is the student's own work and is deliberately
not generated by the agent.
